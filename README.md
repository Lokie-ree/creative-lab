# Creative Lab

Interactive math learning portfolio. Each module teaches through discovery, manipulation, and earned reveals—formulas appear as confirmation of understanding, not prerequisites.

**"I build interactive experiences that help people understand things they thought were hard."**

## Getting Started

```bash
pnpm install
pnpm dev
```
